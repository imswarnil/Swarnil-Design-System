# Media credits

These files exist so the documentation can show real photographs and real
footage rather than grey rectangles. None of them is part of the design system;
`dist/` ships no images at all, and a project consuming the package never
downloads any of this.

## Photographs

`camera.jpg` `city.jpg` `coast.jpg` `code.jpg` `desk.jpg` `night.jpg`
`peak.jpg` `portrait.jpg` `road.jpg` `studio.jpg`

Sourced through [Lorem Picsum](https://picsum.photos), which serves photographs
from [Unsplash](https://unsplash.com) under the
[Unsplash Licence](https://unsplash.com/license) — free to use, no permission
needed, no attribution required (given here anyway). Re-encoded to ~1100px JPEG
so the docs stay light.

## Footage

`loop.mp4`, `loop.jpg` — an eight-second, silent, 880px excerpt of
**Big Buck Bunny**, © 2008 Blender Foundation, released under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). See
[peach.blender.org](https://peach.blender.org). Trimmed past the title card and
re-encoded; the poster is a frame from the same excerpt.

Swap all of it for your own work when you take this site — that is what the
placeholders are for.
