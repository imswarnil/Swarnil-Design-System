Eight ramps, ninety-seven tones, and why dark mode is not an inversion. I rebuild the whole colour layer from an empty file, measure every pair against the contrast target instead of trusting my eyes, and end up deleting more than I add.

Show the full descriptionHide the description

The short version: a colour system is not a palette. A palette is a set of nice colours; a system is a set of promises about which colour is allowed where. The moment you name one primary blue you have written the rebrand into the codebase.

Everything in this episode is in the design system repo, MIT licensed. The ramps are generated in OKLCH so that a step is a perceptual step rather than a hex value someone liked.

Corrections: at 13:10 I say "APCA 60" — the target in the repo is 75 for body text. The narration is wrong; the code is right.
