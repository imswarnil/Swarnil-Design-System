Decide once. Then stop deciding.

Why a token-first design system is the only kind that survives a rebrand — and how three variables carry a whole site.

SSwarnil Singhai
2026-09-07 · 8 min read

I kept rebuilding the same buttons. Not because the old ones were wrong, but because every new project asked me to decide again — sixteen or twenty, grey or greyer, round or rounder — and every time I decided slightly differently.

The cost of deciding twice

A design decision is cheap to make and expensive to keep. The first time you pick a corner radius it costs nothing. The fortieth time, in a different file, on a different Tuesday, it costs consistency — and consistency is the only thing a solo creator has that a team can't buy.1

So the rule became: every value is a variable off a ladder. Nothing invents a number. If a component needs a size that is not on the ladder, the ladder is wrong or the component is.

Three variables

Here is the entire rebrand. Everything else on this page follows from it — the buttons, the badges, the graded photographs, the record dot in the footer.

The trick is not the variables. Everybody has variables. The trick is that components read only the second tier — --accent, never --signal-500 — so the primitive can change under them and nothing has to know.

Try it on this page

Open the inspector, set --accent on :root to any colour, and watch the graded photograph, the tags and the footer dot follow.

What it buys you

  • A new project starts at the finish line. The first commit is content.
  • A rebrand is an afternoon, and it is one commit.
  • Dark mode is one block of tokens, not a second stylesheet that drifts.2

The one thing it does not buy you is taste. A ladder makes the wrong decision consistent too.

The catch

You have to actually stop deciding. That is harder than it sounds, because deciding is fun and the ladder is boring. The discipline is to treat a one-off as a bug report against the system, fix it there, and let the fix land everywhere at once.

That is the whole idea. Decide once. Then stop.

  1. Two people with a shared Figma file will drift less than one person across two years. The system is how one person becomes two. ↩
  2. The previous version of this site kept a hand-maintained dark block and a prefers-color-scheme copy. The copy had already drifted by three tokens when I found it. ↩
